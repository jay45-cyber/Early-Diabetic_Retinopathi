# Development Logs

This directory stores contemporaneous, dated development logs for every substantial work item across the project lifecycle, complying with the **Mandatory Documentation Rule** in the master research specification.

## Logging Rules
1. Every major engineering or research activity must instantiate a new report using [`WORK_ITEM_TEMPLATE.md`](WORK_ITEM_TEMPLATE.md).
2. The report must record exact commands, configuration values, files modified, tests executed, actual outputs, errors encountered, root causes, and resolutions.
3. No credentials, tokens, PHI, or raw patient records may ever appear in these logs.
4. Each completed log is cross-referenced in [`../PROJECT_STATUS.md`](../PROJECT_STATUS.md) and [`../PROGRESS_TRACKER.md`](../PROGRESS_TRACKER.md).
